### Jegyzetek
1. **Gigi** a **Luigi** becézője (mint a magyar *Laci* a *László*-é).
2. Mozgást jelentő igék után **a** + főnévi igenév: **vieni a fare** (jössz csinálni), **vado a mangiare** (megyek enni). A főnévi igenév végződése **-are, -ere, -ire**: **parlare, leggere, venire**. **Vieni** a **venire** (jönni) alakja: **vengo, vieni, viene**.
3. **Non ho tempo** = nincs időm (szó szerint: nem birtoklok időt). Az olaszban *nincs külön „nincs” szó*: **non c'è** = nincs (ott), **non ho** = nincs nekem. A tagadás mindig **non** + ige.
4. Birtokos névmás *névelővel*: **il mio libro** (a könyvem), **il tuo**, **il suo**; nőnem: **la mia, la tua, la sua**. A névmás a birtok neméhez igazodik, nem a birtokoséhoz: **il suo titolo** = az ő (a könyv) címe. Kivétel: egyes számú rokonsági szavak névelő nélkül: **sua moglie** (9. mondat).
5. **Eccolo** = **ecco** + **lo**: itt van (az). A hangsúlytalan névmás az **ecco** végéhez tapad: **eccola, eccoli**.
6. Az elöljárószók összeolvadnak a határozott névelővel: **su + il = sul**, **in + il = nel**, **a + il = al**, **di + il = del**, **da + il = dal**. Ami a magyarban rag (*asztal-on*), az olaszban elöljárószó + névelő (**sul tavolo**).

### 1. gyakorlat — Fordítsa le
1. Vado a passeggiare. → Megyek sétálni.
2. Maria è molto bella. → Mari nagyon szép.
3. Studio in una piccola città. → Egy kis városban tanulok.
4. Il mio vino è sul tavolo. → A borom az asztalon van.
5. Leggo solo in italiano. → Csak olaszul olvasok.
6. Vorrei tre libri interessanti. → Kérek három érdekes könyvet.

### 2. gyakorlat — Egészítse ki
1. Olvasok egy érdekes könyvet. → Leggo un **libro** interessante.
2. A férjem nincs otthon. → Mio **marito** non è a **casa**
3. Mit csinál Pierino a szobában? → Cosa **fa** Pierino in **camera** ?
4. Egy különös nyelvet tanulunk. → **Studiamo** una lingua particolare.
5. Miért nem sétálsz? → **Perché** non passeggi?
6. Önök is olvasnak? → Anche **voi** leggete?
